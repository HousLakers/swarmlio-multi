# 论文逐节写作框架 v3

日期：2026-09-08。阶段：`PAPER-REWRITE-V3-FRAMEWORK`。状态：`FRAMEWORK_READY_FOR_REVIEW`。

本轮目标是按《论文框架.docx》重写可审阅论文，不是生成达标证明。暂定题目：**面向国产算力的多无人机具身智能感知与弹性探索系统**。写作定位为系统工程论文：以系统组成、任务协议和分层测量为贡献，措辞遵守用户要求的保守证据边界。作者、单位、最终题目和篇幅尚未确定，不阻碍本轮框架及带占位符草稿。

## 1. 阶段合同与授权

- 输入：用户点名的规则、交接说明、evidence matrix、v2 框架、skills 指南、v1 正文/claim/citation/QA、三幅 SVG、两套 Archify JSON/HTML、原始 docx 与赛题 PDF；定量核验仅沿上述材料点名的精确索引读取。
- 输出顺序：本文件 → 在会话中报告框架 → `draft/paper_draft_v2.md`、`claim_ledger_v2.md`、`citation_plan_v2.md`、`qa_report_v2.md`，以及本论文目录内的图表、参考文献和静态审校材料。
- 允许修改：本轮新增论文材料与派生图表；在三个正式状态文件中追加简短写作交接。保留 v1、旧框架与旧 SVG 原件。
- 禁止动作：运行 ROS/PX4/Gazebo/AirSim/SSH/飞行或低级终端实验；修改远端、源码、原始 runroot；签发实验 approval；commit/push。
- 验收：7 章、20 个规定小节；标题按 docx 核对；有效数字与精确指标文件一致；每个缺失结果保留五字段占位符；图表有来源、层级、场景、n、统计方法和限制；不得把语法/数字一致性写成实验复现。
- 阶段顺序依据用户本轮第 3、4、13 项：先保存并报告框架，再执行已请求的完整重写。skills 的默认逐阶段询问不增设重复批准；任何新增实验或证据强度提升仍不在授权内。
- 回滚点：此前所有文件保留；本轮产物独立版本化，无需改写既有材料。

## 2. 从 v1 到 v2 的结构诊断

| 问题 | 对论证的影响 | 本轮处理 |
|---|---|---|

不得照搬旧报告中的“显著”“全部最优”“20% 丢包不可能误报”等结论。本轮重新计算统计值属于结果核验；其后 `polish-prose` 冻结数字、单位、引用和证据等级，只改语言。

## 5. 逐节写作合同

### 1.1 项目背景（简洁）

任务：用两至三段从未知空间的定位、探索问题引出资源和协同约束。首段写 GNSS 不可用、地图未知的民用搜索/巡检问题；次段解释多机重复工作、状态滞后与节点失联；末段引出感知—任务—控制系统。赛题仅作为需求来源，不据此推断本项目已达标。证据：所给赛题 PDF 第 2—3、6 页；算法动机由已核验文献支撑。过渡到研究路线，不写操作过程。

### 1.2 研究现状（简洁）

按五个主题组织紧凑段落：单机/协同 LIO；frontier 与轨迹规划；多机分配；通信与失效弹性；机载计算评估。每段写已有方法解决的具体问题、该问题与本系统的关系、本文的验证范围。RACER 为最接近的探索框架，明确继承与本地增量。表 1 比较研究对象、方法和本文接口，不填缺证的性能排名。来源须为本轮检索到的原论文、作者项目或出版记录；查不到的文献单列待补，不借相邻主题凑数。

### 1.3 项目目标

先给系统型贡献，再给指标与后续章节的对应关系。三项技术目标为感知建图、探索分配、弹性任务协议；平台约束和验证方法贯穿三项。表 2 列赛题原始阈值、测量对象和所在章节，不放含混的“达标”。功耗对象写机载计算平台；地图要求保留“分辨率不低于 5 厘米”，其验收语义为待确认项。

### 3.1 swarm-lio算法原理

以文献为依据写惯性传播、点云去畸变、点到面约束、迭代滤波和多机相对状态。只使用有来源的原理或明确标注的概括，不把简化状态向量冒充参考算法的完整状态。给出项目输入/输出与参考算法的关系；部署版本和归档源码未绑定的完整协同功能保持 partial。末段明确三机矩阵用 GT 注册，不能验证 LIO 定位误差。

### 3.2 Racer与单机优化

### 3.3 自适应弹性决策（20%丢包率与单机掉线，在线重规划响应不超过2s？）

分别写持续失联和随机任务消息丢弃两条状态链。掉线：在线→疑似失联→确认→释放→接管→重规划。丢包：提案发送即本地应用→同 stamp 重传/幂等应答→心跳认领协调；明确拒绝回滚、未确认超时保持乐观状态，不能泛称“超时必回滚”。图 2 为状态图，机制示意不放未测时间轴。响应定义为事件、检测、分配、新轨迹可用、执行生效的时间分解；≤2 s 比较必须同时检查规定起止点和最大值，仅有 P95 不足以证明上界。

## 9. Skills 与静态核验路径

`paper-profile` 固化用户已给定的系统定位和保守论断约束；`refactor-structure` 形成上述问题—贡献—证据路径；`orchestrate-paper` 将框架、文献、结果、写作、审校各阶段记入论文目录的 INDEX。`literature-review` 建立有检索来源的五主题 corpus；`draft-related-work` 写 1.2；`verify-citations` 输出引用核验报告。`verify-claims` 建立逐条论断账本；`verify-results` 重算本地指标并标明未重新实验；`polish-prose` 冻结技术内容后去除套话；`assess-paper` 汇总适用于此草稿的检查，缺输入的投稿/原创性/评审项如实标未执行；`archify` 交付总体流程图与确定性校验 receipt。
